# Sanuvia Phase 0 — Engineering Review Dataset

The official dataset for stress-testing the Persistent Reasoning Core before engineering review. Each case is a deterministic sequence of **canonical EvidenceRecords** plus the **expected reasoning evolution** after every step.

- **Static engineering assets** — not generated by the reasoning engine.
- **Machine-verified** — every expected value below is asserted against the real engine by `tests/adapters/test_review_dataset.py`, so the annotations cannot drift.
- **Deterministic** — identical results on every run (`ManualClock` + `SequentialIdGenerator`).

### How to use in the harness

Open the review harness → **Sample Library** → find the `D1…D12` cases (tagged *Review Dataset*) → **Load** (creates a new editable Test Case) → **Run Full Sequence** (or step through with **Run Next Step**) → inspect every panel. Loading never mutates the originals; you can duplicate, edit, and save as a new Test Case, or Export/Import as JSON.

### Field legend

Canonical EvidenceRecord fields per step: **RawObservation**, **EvidenceClass**, **Source**, **ClassificationStatus**, **EvidenceReliability**, **ClassificationConfidence**, **ProvenanceConfidence**, **Metadata**, **Supports**, **Contradicts**, **Proposals** (only when introducing hypotheses).

Expected reasoning evolution per step: **version** (current WorldModel version; unchanged on a hold — note a held step still consumes a version id, so the next committed version skips a number), **committed** (did a new version commit; `hold` = model unchanged), **inquiry** (is an Inquiry active), **predictions** (hypotheses holding an active Prediction), **anomaly** (AnomalyResolution disposition: revise/escalate/reject), **uncertainty** (ModelUncertainty trend vs previous step).
